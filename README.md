# Davide Guerra website

Bilingual static website. English is the default language at the root; Italian lives under `/it/`.

## Build

Run `node build-site.js` from this folder. The build writes the canonical page directories and the legacy redirects.

## Content rules

Only Chapter One of Daniel Belmont is published. Chapters Two–Seven are private continuity material and are not included in the site output. Newsletter forms use the existing Brevo endpoints and double opt-in fields.
